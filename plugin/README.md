# Refactor Plugin Demo

This is a simple proof-of-concept extension for VS Code that demonstrates how to show a refactoring suggestion in a diff view.

## How to Run

1.  Open this `plugin` directory in VS Code.
2.  Press `F5` to open a new Extension Development Host window with this extension loaded.
3.  Open any code file.
4.  Select some text.
5.  Click the sparkle icon (✨) in the top-right of the editor.
6.  A diff view will open with your selection on the left and a hardcoded replacement on the right.
